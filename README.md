# freelens-rabbitmq-extension

Freelens extension for RabbitMQ: Kubernetes-native discovery of RabbitMQ
clusters, port-forwarded Management API, queue, exchange, connection and
message inspection.

This repository is being set up. The extension code is being moved here from
https://github.com/Tal-Naeh/freelens-rabbitmq-extension, where it was
originally developed by Tal Naeh, who maintains it here as well.
